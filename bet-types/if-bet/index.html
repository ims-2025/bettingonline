Bet Types

What is an If Bet?

An "if bet" is a conditional wager: place bet B only if bet A wins. It limits your downside while preserving multi-bet upside.

How if bets work

You write up two bets: A and B. The if bet only places B if A wins. If A loses, you only lose A — B is never placed.

When to use if bets

When you want exposure to two outcomes but don't want full parlay risk and don't want to commit to two separate stakes upfront.
